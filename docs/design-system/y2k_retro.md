# MASTER PROMPT — Y2K RETRO UI DESIGN SYSTEM

Design a modern digital application using **Y2K Retro Futuristic UI** aesthetics, inspired by early 2000s technology, cyber culture, futuristic interfaces and digital experimentation.

## 1. Visual Direction

- Futuristic early-2000s visual language.
- Metallic, chrome and glossy surfaces.
- Iridescent and holographic visual accents.
- Digital gradients and reflective materials.
- Experimental geometric compositions.
- Playful technology-inspired visual elements.
- A balance between nostalgic aesthetics and modern usability.

## 2. Color System

Primary:
- Metallic Silver.
- Chrome.
- Electric Blue.
- Cyber Cyan.

Secondary:
- Hot Pink.
- Purple.
- Lavender.
- Holographic White.

Use dark navy or deep purple for selected dark interface variations.

Avoid limiting every interface to a single color combination. Establish a coherent palette based on the application's identity.

## 3. Typography

- Futuristic geometric sans-serif.
- Extended and condensed display typography.
- Bold headings with strong visual presence.
- Digital-inspired labels and numerical displays.
- Use readable modern sans-serif fonts for long-form content.

## 4. UI Components

- Glossy buttons with reflective highlights.
- Metallic navigation bars.
- Translucent panels.
- Holographic badges.
- Futuristic toggles and sliders.
- Chrome-inspired icons.
- Gradient progress indicators.
- Floating digital widgets.
- Experimental decorative elements.

## 5. Surface & Effects

- Chrome and metallic gradients.
- Subtle glossy reflections.
- Controlled glow effects.
- Iridescent color transitions.
- Layered translucent surfaces.
- Soft outer highlights.

Use these effects selectively. Avoid excessive visual noise.

## 6. Layout

- Experimental but structured compositions.
- Floating panels and modular sections.
- Asymmetric layouts when appropriate.
- Strong separation between primary and secondary content.
- Clear interaction hierarchy.
- Responsive desktop and mobile layouts.

## 7. Motion & Interaction

- Smooth transitions.
- Subtle hover reflections.
- Animated gradient highlights.
- Responsive button feedback.
- Lightweight futuristic micro-interactions.

## 8. Avoid

- Generic corporate SaaS dashboards.
- Excessive glassmorphism.
- Overusing neon glow.
- Unreadable futuristic typography.
- Random decorative elements.
- Excessive gradients without hierarchy.

## 9. Design Objective

Create a polished application that feels like a futuristic digital product imagined in the early 2000s, redesigned with modern usability, accessibility and production-quality UI consistency.

Prioritize visual identity, usability and coherent component design.
