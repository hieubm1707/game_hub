Design a game interface using **Cartoon Fantasy Game UI – Cozy Farming RPG Style**.

### Visual Direction
- Playful, colorful, friendly cartoon game aesthetics.
- Inspired by farming simulation games and casual RPG interfaces.
- Warm wooden textures and earthy brown backgrounds.
- Large rounded panels with thick dark outlines.
- Strong drop shadows to create depth.
- Colorful illustrated item icons with a slightly 3D appearance.
- Bold cartoon typography with subtle text shadows.

### Color System
- Primary: Warm Brown, Dark Brown, Orange.
- Secondary: Grass Green, Golden Yellow.
- Accent: Blue, Purple, Pink.
- Rarity colors:
  - Common: Gray.
  - Uncommon: Green.
  - Rare: Blue.
  - Epic: Purple.
  - Legendary: Gold.

### UI Components
- Rounded inventory cards.
- Large illustrated item icons.
- Color-coded rarity badges.
- Prominent currency indicators.
- Chunky buttons with thick borders.
- Large readable prices and quantities.
- Consistent card spacing and alignment.

### Layout
- Game-oriented interface.
- Clear visual hierarchy.
- Large touch-friendly interactive elements.
- Organized inventory and shop layouts.
- Responsive desktop and mobile layouts.

### Avoid
- Generic SaaS dashboard aesthetics.
- Minimalist flat design.
- Glassmorphism.
- Thin borders.
- Excessive gradients.
- Corporate typography.
- Photorealistic UI elements.

The final result should feel like a polished, production-ready interface from a charming farming RPG or casual simulation game.
