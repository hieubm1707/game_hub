# MASTER PROMPT — COZY FARMING GAME UI DESIGN SYSTEM

Design a game interface using **Cozy Farming Simulation UI** aesthetics, inspired by relaxing farming games, village simulators, gardening games and cozy life simulation experiences.

## 1. Visual Direction

- Warm, friendly and relaxing atmosphere.
- Nature-inspired visual identity.
- Charming cartoon illustrations.
- Soft organic shapes.
- Rustic and handcrafted visual details.
- Friendly and approachable interactions.
- A sense of warmth, simplicity and progression.

## 2. Color System

Primary:
- Warm Wood Brown.
- Earth Brown.
- Grass Green.
- Leaf Green.

Secondary:
- Cream.
- Warm Beige.
- Soft Yellow.
- Terracotta Orange.

Accent:
- Strawberry Red.
- Sky Blue.
- Lavender.
- Golden Yellow.

Maintain a warm, harmonious palette throughout the application.

## 3. Typography

- Rounded and friendly sans-serif fonts.
- Soft display typography.
- Readable medium-to-bold headings.
- Clear numerical displays.
- Friendly labels and status indicators.

Avoid overly technical or corporate typography.

## 4. UI Components

- Wooden inventory panels.
- Rounded item cards.
- Seed and crop illustrations.
- Resource counters.
- Harvest progress indicators.
- Gardening tool icons.
- Friendly action buttons.
- Daily reward cards.
- Quest and mission panels.
- Inventory slots.
- Shop item lists.

## 5. Surface & Materials

- Wooden textures.
- Natural paper surfaces.
- Subtle fabric and handcrafted patterns.
- Soft borders.
- Gentle shadows.
- Organic decorative elements.

Textures should be subtle enough to preserve text readability.

## 6. Game Elements

- Seeds, crops, fruits and vegetables.
- Farming tools.
- Land and garden decorations.
- Resource management indicators.
- Crop growth stages.
- Harvest rewards.
- Daily missions.
- Seasonal events.

Use consistent illustration styles across all game assets.

## 7. Layout

- Friendly modular layouts.
- Clear inventory organization.
- Large interactive item slots.
- Easy-to-understand resource hierarchy.
- Comfortable spacing.
- Touch-friendly controls.
- Responsive desktop and mobile layouts.

## 8. Motion & Interaction

- Gentle button animations.
- Harvest reward feedback.
- Smooth progress animations.
- Subtle item hover effects.
- Friendly confirmation interactions.
- Small celebratory animations for achievements.

## 9. Avoid

- Aggressive neon colors.
- Industrial interfaces.
- Excessive visual complexity.
- Corporate dashboard aesthetics.
- Photorealistic textures.
- Tiny touch targets.
- Inconsistent illustration styles.

## 10. Design Objective

Create a polished cozy farming game interface that feels relaxing, charming, welcoming and rewarding.

The experience should encourage exploration, collection, progression and repeated engagement without overwhelming the player.
